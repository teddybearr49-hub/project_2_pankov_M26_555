## Управление таблицами

- `create_table <имя> <столбец:тип> ...` — создать таблицу (типы: `int`, `str`, `bool`)
- `list_tables` — список таблиц
- `drop_table <имя>` — удалить таблицу
- `help` — справка
- `exit` — выход

## CRUD-операции

- `insert into <таблица> values (<v1>, <v2>, ...)` — добавить запись
- `select from <таблица>` — показать все записи
- `select from <таблица> where <столбец> = <значение>` — фильтр
- `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` — обновить
- `delete from <таблица> where <столбец> = <значение>` — удалить
- `info <таблица>` — информация о таблице

Строковые значения указываются в кавычках: `"Sergei"`.
